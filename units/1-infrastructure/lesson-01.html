Lesson 1.1: Virtualization & Proxmox Concepts

BABY

📚 What You Are Learning

One concept: Understanding virtualization technologies and when to use VMs, containers, or bare metal for your homelab.

By the end of this lesson, you will understand the differences between:

  • Bare metal installations
  • Virtual Machines (VMs)
  • Containers (Docker)
  • Hypervisors (Proxmox, Hyper-V, ESXi)

✅ You Should Already Have

  • A computer with 8GB+ RAM running Windows 10/11 OR Ubuntu/Debian Linux
  • Basic understanding of operating systems
  • Internet connection to download software

📖 New Words

Technical terms you'll learn in this lesson (click to see definitions):

  • Container — Lightweight isolated application environment
  • Docker — Platform for running containers
  • Docker Image — Template for creating containers
  • Hypervisor — Software layer that creates and runs virtual machines
  • VM (Virtual Machine) — Fully isolated virtual computer with its own OS

🔧 Understanding Virtualization Options

Option 1: Bare Metal + Docker (Simplest for Beginners)

What it is: Install Ubuntu/Debian directly on hardware, then run Docker containers for all services.

Pros: Simple, no virtualization overhead, great for a single dedicated server

Cons: Less flexible if you want multiple isolated environments

Best for: Your first homelab, single-purpose servers

Option 2: Windows WSL2 + Docker Desktop (Best for Windows Users)

What it is: Use Windows as your daily driver, run a lightweight Linux VM (WSL2) inside Windows, run Docker containers in WSL2.

Pros: Keep using Windows, easy setup, great for laptops

Cons: WSL2 has some quirks with networking and file I/O performance

Best for: Windows users who want to learn Docker without dedicating hardware

Option 3: Proxmox Hypervisor (Advanced)

What it is: Install Proxmox VE (a hypervisor) on bare metal, create multiple VMs and LXC containers inside it.

Pros: Run multiple isolated operating systems, snapshots, easy backups, HA clusters

Cons: More complex, requires dedicated hardware, learning curve

Best for: Advanced users with dedicated homelab hardware

Windows WSL2 Setup

Enable WSL2

Open PowerShell as Administrator and run:

wsl --install

This installs WSL2 and Ubuntu 22.04 by default. Reboot when prompted.

Verify WSL2 Installation

After reboot, open PowerShell and check:

wsl -l -v

You should see Ubuntu with VERSION 2.

Install Docker Desktop

Download Docker Desktop from docker.com

Run the installer and enable WSL2 integration during setup.

Configure WSL2 Integration

Open Docker Desktop → Settings → Resources → WSL Integration

Enable integration with your Ubuntu distribution.

Test Docker in WSL2

Open Ubuntu terminal (search "Ubuntu" in Windows Start menu) and run:

docker --version
docker ps

You should see Docker version output and an empty container list.

Linux Bare Metal Setup

Install Ubuntu Server 22.04 or 24.04

Download Ubuntu Server ISO from ubuntu.com

Create bootable USB with Rufus (Windows) or Etcher (Mac/Linux)

Boot from USB and follow the installation wizard. Choose "Use entire disk" for simplicity.

SSH Access (Optional but Recommended)

During Ubuntu install, enable OpenSSH server when prompted.

After install, find your server's IP address:

ip addr show

From another computer, connect via SSH:

ssh username@SERVER-IP

Update System

sudo apt update && sudo apt upgrade -y

Install Docker Engine

sudo apt install docker.io docker-compose-plugin -y
sudo systemctl enable --now docker
sudo usermod -aG docker $USER

Log out and back in for group membership to take effect.

Test Docker

docker --version
docker ps

You should see Docker version output and an empty container list.

Proxmox VE Setup (Advanced)

💡 Proxmox Note: This is an advanced path. For your first homelab, we recommend starting with Windows WSL2 or Linux bare metal, then migrating to Proxmox later.

Download Proxmox VE ISO

Get the latest Proxmox VE ISO from proxmox.com

Create bootable USB with Rufus or Etcher.

Install Proxmox VE

Boot from USB and follow the graphical installer.

Set a static IP for the Proxmox host (e.g., 192.168.1.100).

After reboot, access web UI at https://PROXMOX-IP:8006

Create a VM for Docker

In Proxmox web UI, click "Create VM"

Upload Ubuntu Server 22.04 ISO

Allocate 4GB+ RAM, 2+ CPU cores, 50GB+ disk

Start VM and install Ubuntu Server inside it

Install Docker in the VM

Follow the same Docker installation steps as Linux bare metal (above).

Optional: LXC Container for Docker

Advanced users can run Docker in an LXC container instead of a VM.

Read: Proxmox LXC documentation

🔧 Troubleshooting Decision Tree

Problem: "docker: command not found"

Windows: Make sure Docker Desktop is running (check system tray)
Linux: Run sudo apt install docker.io docker-compose-plugin
Both: Close and reopen your terminal

Problem: "permission denied while trying to connect to the Docker daemon"

Linux: Run sudo usermod -aG docker $USER then log out and back in
Windows: Make sure WSL integration is enabled in Docker Desktop settings

Problem: WSL2 not installing on Windows

→ Check Windows version (need 2004 or later): run winver
→ Enable virtualization in BIOS (Intel VT-x or AMD-V)
→ Run Windows Update to get latest WSL2 kernel
